enum logcpp::default_severity_levels

The default severities that are used in LibLogC++.

Note
In all cases, the value
- 0 defaults to off
- 1 defaults to critical
- The last element has to be called SEVERITY_SIZE to determine
the size of the enum
- You are not allowed to assign values to the enum members
- For better use and readablity, a severity_level enum is defined at global
library scope, but you also may define it in your own namespace.
- The higher the enum value, the less critical is this severity
