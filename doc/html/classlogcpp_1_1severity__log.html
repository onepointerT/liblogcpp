Detailed Description

template<typename severity_t>
class logcpp::severity_log< severity_t >

Abstract description of a severity logger.

Note
severity_t: The type of severity that is to be used
severity_name: A function taking a severity_t and returning its name
max_name_length: A function returning the amount of characters of the longest severity name (used for alignment)
